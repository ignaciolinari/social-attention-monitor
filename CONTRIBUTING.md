# Contributing to SAM

Thank you for your interest in contributing to Social Attention Monitor.

## Development Setup

1. Fork and clone the repository.
2. Create a virtual environment and install dev dependencies: `make dev`
3. Start Postgres and Redis: `make db-up`
4. Apply migrations: `alembic upgrade head`
5. Run tests: `make test`

See [Setup & Configuration](docs/setup.md) for full details.

## Code Style

- **Linting**: `ruff check src tests`
- **Formatting**: `ruff format src tests`
- **Type checking**: `mypy src --ignore-missing-imports`

Run `make ci-check` to execute all checks as in CI.

## Pre-commit

`make dev` installs pre-commit hooks. They run automatically before each commit. To run manually:

```bash
pre-commit run --all-files
```

## Pull Request Workflow

1. Create a feature branch from `main`.
2. Make your changes. Ensure `make ci-check` passes.
3. Add or update tests as needed.
4. Update documentation if behavior changes.
5. Open a PR with a clear description of the change.
6. Address review feedback.

## Running Tests

- Unit tests: `make test` or `pytest tests/ -v --cov=sam`
- Integration tests (requires Docker): `make test-integration`
- Fast run (no coverage, stop on first failure): `make test-fast`

## Database Migrations

To create a new migration:

```bash
make db-migrate
# Enter a descriptive message when prompted
```

Always review autogenerated migrations before committing.

## Reporting Issues

Use GitHub Issues for bugs and feature requests. Include:

- SAM version and Python version
- Steps to reproduce
- Expected vs actual behavior
- Relevant logs or error messages
